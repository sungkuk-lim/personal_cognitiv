# 모담넷(MemoryOS) 상세 이용 가이드 (사용자용)

**버전 1.0.29 (33) · 2026년 8월**

앱 설정 → **이용 가이드**는 선택한 언어로 요약이 표시됩니다.  
웹 상세 안내: https://sungkuk-lim.github.io/personal_cognitiv/user_guide.html

## 1. 모담넷이란?

음성·사진·동영상·텍스트로 남긴 **기억**을 타임라인에 쌓고, **관계망**으로 사람·장소·사건을 연결해 다시 찾아 주는 개인 기억 앱입니다.

- **기억 저장** — 말하기, 사진·동영상, 메모, (선택) 위치
- **자연어 검색** — 「지난달 제주도에서 뭐 했었는지」처럼 말하듯 질문
- **관계망** — 허브·위성 트리, 종류별 색상, 드래그·롱프레스 이동
- **회상** — 월별 갤러리, 사진 스와이프, 장소 근처 알림, 하이라이트에서 보기·영상·관계
- **기억 영상 (Pro)** — 사진으로 짧은 필름 미리보기·mp4 저장/공유, 만든 영상은 하이라이트 썸네일로 다시 재생
- **프라이버시** — 게스트·프라이버시 모드로 기기에만 저장 가능
- **언어** — 한·영·일·중(간/번)·스·프·독·브라질 포·베트남 (설정 상단)

**핵심:** 입력은 항상 **자연어**로 하세요. 사람·장소·날짜·감정을 함께 말하면 검색·관계망·회상이 더 정확해집니다.

## 2. 처음 사용하기

1. **게스트**로 바로 쓰거나 **이메일 로그인**으로 클라우드·Pro를 준비합니다.
2. 하단 탭: **타임라인 · 검색 · 관계망 · 회상** (설정은 상단 톱니).
3. 첫 기억 예: 「오늘 광안리에서 어머니와 저녁 먹었어.」
4. 타임라인 카드 확인 → 관계망에서 사람·장소 연결 확인.
5. (Pro) 설정 → **기억 영상 만들기** 또는 회상/하이라이트에서 필름 미리보기.

**권한:** 마이크 · 카메라/사진 · 알림 · 위치(항상 허용 권장 — 장소 회상).

## 3. 타임라인 — 기억 저장

| 방법 | 하는 일 |
|------|---------|
| 마이크 | 음성 또는 키보드 → 분석·저장 |
| 카메라 | 촬영/갤러리. 한 카드에 사진 여러 장 |
| 카드 탭 | 상세 · 편집 · 미디어 · 관계 태그 수정 |

**화면:** 같은 날짜끼리 묶여 보이고, 카드는 왼쪽 글·오른쪽 사진 썸네일 형태입니다. 키워드는 가로로 스크롤됩니다.

**잘 되는 말하기**
- 「어제 어머니와 강남 식당에서 저녁 먹었어.」
- 「6월 22일 길안천에 가족과 놀러 갔다.」

카드에서: 본문 편집, 관계 태그 수정(관계망 반영), 사진·동영상 추가/삭제, 키워드 칩 → 관계망 포커스.

## 4. 검색 — 자연어로 찾기

상단 검색창에 질문을 넣고 검색하면, **현재 검색 결과만** 한 화면에 표시됩니다. (이전 검색이 아래로 쌓이지 않습니다.)

| 구분 | 조건 | 화면 |
|------|------|------|
| 로컬 결과 | 항상(기기 기억) | 사진·제목·날짜·키워드 카드 목록 |
| AI 요약 | 로그인 + Pro | 목록 아래 강조 박스에 한 줄 요약 |

| 모드 | 조건 | 예시 |
|------|------|------|
| AI 의미 검색 | 로그인 + Pro | 「지난달 제주도에서 뭐 했었는지 알려줘」 |
| 로컬 자연어 | 게스트·무료·프라이버시 | 「어머니와 저녁」「오늘 사진」「광안리」 |

**필터 칩:** 복합 조건이 잡히면 상단에 칩이 뜹니다. **전체 해제**로 검색을 초기화합니다.

팁: 카드에 보이는 이름·장소·날짜를 말하듯 입력. 「오늘/어제/이번 주/지난달」 지원.

## 5. 관계망 — 연결 보기

| 조작 | 설명 |
|------|------|
| 핀치 / 빈 곳 드래그 | 확대·화면 이동 |
| 노드 드래그 | 위치 이동(저장) |
| **허브 롱프레스 후 드래그** | 관련 위성과 함께 이동 |
| 기간 | 7 / 30 / 90일 / 전체 |
| 렌즈 | 사람 \| 기억 |
| 색상 | 사람·장소·활동·반려 등 종류별 |

### 사진이 보이는 방식

- 기억 카드에 올린 사진은 **그 기억 카드**에 먼저 표시됩니다.
- 하루 묶음 허브는 **아직 다른 카드에 쓰이지 않은** 사진이 있을 때만 썸네일을 보여 줍니다.
- 사람·장소 위성에 올린 미디어는 **그 노드에만** 표시됩니다.

(Pro) 노드 AI 대화로 디테일 보강 가능.

## 6. 회상

- 월별로 펼침·접기
- 큰 사진 + 작은 사진 모자이크, **좌우 스와이프**로 넘기기
- 사진 탭 → 확대 보기 · 미디어 관리
- 아래쪽 **미니 관계망**으로 연결 미리보기
- 「관계망」→ 그 기억만 포커스
- (Pro) 하이라이트 **영상** 버튼으로 기억 필름 만들기
- 만든 영상은 하이라이트 카드 **썸네일** — 탭하면 바로 재생
- 회상 보기 모드(설정): 공유 / 라이트 / 갤러리

### 하이라이트 카드

아이콘만 있던 버튼을 **보기 · 영상 · 관계** 글자로 바꿨습니다. 기억 내용이 거의 같은 카드(사람/사건만 다른 경우 등)는 한 장으로 합칩니다.

| 버튼 | 하는 일 |
|------|---------|
| **보기** | 그 사람·장소의 사진·동영상 슬라이드 (카드 전체 탭과 같음) |
| **영상** | (Pro) 연결된 사진으로 기억 영상 만들기 |
| **관계** | 관계망에서 그 이름만 포커스 |

왼쪽 위 **사람 / 장소 / 사건** 라벨로 종류를 구분합니다. 제목을 길게 누르면 표시 이름을 바꿀 수 있습니다.

### 장소 회상 알림

1. 장소 기반 회상 알림 ON + 알림 권한  
2. 위치 **항상 허용**  
3. 기억 저장 시 GPS  
4. 배터리 최적화에서 모담넷 **최적화 안 함**  

과거 GPS 장소 약 250m 이내 재방문 시 푸시.

## 6.1 기억 영상 (Pro)

사진으로 짧은 **기억 필름**을 만들고 기기에 mp4로 저장·공유합니다. (추가 요금 없음 · Google Play 구독에 포함)

### 만드는 방법

1. **설정 → 기억 영상 만들기**, 또는 회상 하이라이트의 **영상** 버튼  
2. 기억에 연결된 사진 또는 갤러리에서 사진 선택  
3. **길이 · 장수 · 필름 템플릿** 선택 — 장면 시간은 영상 길이를 사진 장수로 나눠 자동 배분합니다. 해상도가 낮은 사진은 기기에서 업스케일되어 영상에 들어갑니다.
4. 배경 음악은 **기본 음악 · 음악 없음** 또는 기기에서 **여러 MP3**를 골라 영상 길이에 맞춰 이어 붙입니다
5. 전환은 검정 페이드, **흰 화면으로 이어지기**, 소프트 컷, 슬라이드 등을 고를 수 있습니다
6. **미리보기 → 기억 영상 만들기** → 완성된 실제 영상을 확인한 뒤 **갤러리 저장** 또는 **공유**
7. 회상 하이라이트에서 만든 영상은 해당 카드의 **썸네일**로 남고, 누르면 바로 재생됩니다

### 필름 템플릿 (예)

| 템플릿 | 느낌 |
|--------|------|
| 클래식 | 스튜디오 디졸브 · 균형 색보정 |
| 시네마틱 | 암전 디졸브 · 시네마 그레이드 · 레터박스 |
| 가족 따뜻한 | 따뜻한 톤 · 소프트 컷 · 얼굴 중심 |
| 여행 다이어리 | 밝은 콘트라스트 · 슬라이드 와이프 · 역동적 팬 |
| 인물 포커스 | 피부톤 보정 · 깊은 줌 · 부드러운 디졸브 |
| 추억 앨범 | 필름 그레인 · 페이드 하이라이트 · 느린 호흡 |

### 얼굴 중심 Ken Burns

사진에서 얼굴을 찾아(없으면 시각적 무게중심) **줌·팬의 중심**으로 씁니다. 미리보기와 내보낸 mp4가 같은 초점을 사용합니다.

템플릿마다 색보정·비네팅·그레인·레터박스·줌 호흡(시작·끝 홀드)이 다르며, 장면 전환은 시간을 더하지 않고 앞뒤 장면을 겹칩니다. 얼굴이 화면 밖으로 벗어나지 않는 안전 범위 안에서 부드럽게 움직입니다.

### 내 기기 음악

화면 마지막의 **기기 MP3 배경음악** 버튼에서 MP3·M4A·AAC 등 오디오 파일을 고를 수 있습니다. 선택 음원은 영상 제작과 중단 복구를 위해 앱 내부 WAV로 변환됩니다. 음악은 영상 길이에 정확히 맞춰 반복 또는 잘리며, 영상 길이에 맞춘 부드러운 페이드인·페이드아웃과 나레이션 구간 자동 음량 조절이 적용됩니다.

> 본인이 사용할 권한이 있는 음원만 선택하세요. 음원 선택이나 변환이 실패하면 기본 음악을 계속 사용할 수 있습니다.

### 내보내기 중 앱이 꺼졌을 때

렌더가 중간에 멈추면, 다음에 앱을 열 때 **이어서 완성** 안내가 뜰 수 있습니다. 알림이 오면 앱을 열어 완료하세요. (강제종료 중에도 백그라운드에서 계속 인코딩되지는 않으며, **체크포인트 후 이어하기** 방식입니다.)

## 12. FAQ · 문제 해결

| 증상 | 해결 |
|------|------|
| 회상 알림 없음 | 위치 항상 허용 · 배터리 최적화 해제 · GPS 기억 확인 |
| 옛 이름 노드 | 앱 재시작 · 관계망 데이터 정리 |
| 검색 없음 | 카드에 보이는 단어로 · 프라이버시면 AI 검색 불가 |
| 구매 복원 실패 | **Play 설치본** 확인 · 복원·상태 새로고침 |
| 기억 영상 버튼 없음 / 결제 연동 없음 | Pro 필요 · Play 설치본인지 확인 |
| 하이라이트 버튼 의미를 모름 | **보기**(사진 슬라이드) · **영상**(필름 만들기) · **관계**(관계망) |
| 만든 영상을 다시 못 찾음 | 회상 하이라이트 카드 **썸네일**을 탭 |
| 영상 내보내기 중단 | 앱 재실행 → **이어서 완성** · 사진/오디오 파일이 지워지지 않았는지 확인 |
