# 모담넷(MemoryOS) 이용 가이드

**버전 1.0.1 · 2026년 7월**

---

## 1. 모담넷이란?

모담넷은 **음성·사진·텍스트로 남긴 기억**을 타임라인에 쌓고, **관계망(그래프)** 으로 사람·장소·사건을 연결해 다시 찾아주는 개인 기억 앱입니다.

- **기억 저장** — 말하기만 해도 기록, 사진·메모·위치까지 한 카드로
- **의미 검색** — 「민수랑 먹었던 식당」처럼 자연어 질문 (Pro·클라우드)
- **관계망** — 인물·장소·감정·이벤트가 노드와 선으로 연결된 탐색
- **회상** — 월별 사진·요약, **장소에 가면 알림**으로 과거 기억 소환
- **프라이버시** — 게스트·프라이버시 모드로 **기기에만** 저장 가능

---

## 2. 다른 앱과 다른 관계망

일반 메모·일기 앱은 **시간순 목록**이 중심입니다. 모담넷 관계망은 **「무엇이 서로 연결되는가」** 를 먼저 보여 줍니다.

| 비교 | 일반 메모·갤러리 | 모담넷 관계망 |
|------|------------------|---------------|
| 구조 | 폴더·태그·날짜 | **사람·장소·이벤트 허브 + 위성 노드** |
| 연결 | 사용자가 직접 태그 | **본문·AI·규칙으로 자동 추출**, 편집 후에도 재정렬 |
| 탐색 | 검색어 일치 | **키워드 포커스** — 한 사람·장소만 관계망에 집중 |
| 묶음 | 앨범·캘린더 | **하루·사건 허브**, 클러스터 간 **황금 브리지**(같은 사람·장소) |
| 의미 | 없음 | **AI 의미 유사도** 링크(보라색), 관계 라벨(동행·방문·감정) |
| 신뢰 | 태그=사용자 책임 | **GraphEntityContext** — 배지·노드·본문 **단일 진실**, 옛 이름 자동 제거 |
| 회상 | 알림 없음 | **GPS 회상 앵커** — 예전 기록 장소 250m 이내 푸시 |

**모담넷만의 체감:** 타임라인에서 「철수」를 「민수」로 고치면, 관계망·배지·검색 칩에서 **옛 이름 노드가 사라지고** 본문과 맞는 연결만 남습니다.

## 3. 핵심 기능과 활용법

### 3.1 타임라인 — 기억의 흐름

**저장 방법**
- 하단 **마이크** — 음성·키보드 입력 → 「분석 및 저장」
- **카메라** — 촬영 또는 갤러리, 메모로 이름·장소 보강
- 카드 **탭** — 상세 보기·편집·사진 추가·삭제

**활용 팁**
- 짧은 한 문장보다 **사람·장소·감정**을 함께 말하면 관계망 품질이 올라갑니다.
- 예: 「월영교에서 황해순이와 일몰 봤다. 바람이 시원했다.」

### 3.2 검색 엔진

| 모드 | 조건 | 사용법 |
|------|------|--------|
| AI 의미 검색 | 로그인 + Pro + 클라우드 | 「민수랑 먹었던 식당 어디였지?」 |
| 로컬 검색 | 게스트·프라이버시 | 타임라인에 보이는 **단어**로 검색 — 「월영교」「6월」 |

**잘 되는 검색:** 카드에 보이는 이름·장소·날짜  
**어려운 검색:** 「오늘 사진」만 — 요약에 없는 단어는 저장되지 않음

### 3.3 관계망

- **렌즈** — 상단 **사람 | 기억** (같은 데이터, 다른 관점)
- **관계망 AI**(설정) — 켜면 기억 렌즈에 인사이트 한 줄 + 백그라운드 관계 분석
- **핀치·드래그** — 확대·이동, 노드 드래그
- **기간** — 7일 / 30일 / 90일 / 전체
- **키워드 포커스** — 타임라인·회상·검색의 **칩 탭** → 해당 키워드만 서브그래프
- **위성 썸네일** — 사람·장소 등 위성에도 **관련 기억의 사진·영상**이 표시됩니다
- **이벤트 허브 보기** — 사건 중심 레이아웃 전환
- **노드 탭** — 기억 상세, AI 대화(Pro), 미디어·하이라이트
- **연결 차수** — 사람 상세에서 1~5차 연결을 확인할 수 있습니다

**선 색 의미**
- 보라색 실선 — AI 의미 유사도
- 녹색 — 관계 라벨(동행·방문 등)
- 황금 점선 — **다른 날·묶음**을 같은 사람·장소로 연결

### 3.4 회상

- **월별** 사진·요약 갤러리
- **회상 보기 모드**(설정): 공유 / 라이트 / 갤러리
- **장소 기반 회상 알림** — 과거 GPS 장소 재방문 시 푸시 (아래 설정 참고)

### 3.5 홈 화면 위젯

바탕화면 **길게 누르기 → 위젯 → 모담넷 기억 위젯**

- 최신 기억 미리보기 · **기억 저장** · **검색** · **관계망** 바로가기

## 4. 환경설정 완전 가이드

설정은 앱 상단 **톱니(⚙)** → **설정** 탭에서 엽니다.

### 4.0 이용 가이드

| 항목 | 설명 |
|------|------|
| 이용 가이드 및 사용방법 | 앱 안 요약 시트 |
| **PDF 가이드** | 앱 안에서 PDF 보기·공유 |
| **웹 안내** | 브라우저에서 최신 HTML 가이드 열기 |

### 4.1 Pro · 구독

| 항목 | 설명 |
|------|------|
| MemoryOS Pro | 클라우드 동기화·AI 검색·사진 AI·관계망 AI |
| 무료 모드 | 게스트·프라이버시와 같이 **기기 저장 + 로컬 검색** |

### 4.2 회상 · 알림

| 항목 | 설명 |
|------|------|
| 장소 기반 회상 알림 | 과거 GPS 장소 근처에서 푸시 |
| 위치 권한 | **항상 허용** 권장 (앱 종료 후에도 알림) |
| 배터리 최적화 | 일부 기기에서 「최적화 안 함」 |

### 4.3 사진 인식(OCR)

| 모드 | 설명 |
|------|------|
| **하이브리드(추천)** | 대부분의 사진, AI 분석 + 선택적 기기 OCR |
| **저비용** | AI 해상도 낮춤, 월 한도 절약 |
| **AI 전용** | 가장 풍부한 설명 |
| **AI OCR 품질** | 낮음(저렴) / 높음(정확) — 저비용은 항상 낮음 |

### 4.4 관계망 · 신뢰

| 항목 | 설명 |
|------|------|
| **관계망 AI** | 인사이트 표시 + 저장 후 백그라운드 분석 (Pro·로그인·클라우드) |
| **관계망 데이터 정리** | 캐시·중복·옛 이름 정리 |
| **신뢰 대시보드** | AI·로컬 저장 비율 확인 |

### 4.5 프라이버시 · 외관

| 항목 | 설명 |
|------|------|
| **프라이버시 모드** | 새 기억 **기기만**, 클라우드·AI 없음 |
| 테마·언어·다크 모드 | 개인화 |
| 기기 잠금 | 지문·패턴 |

## 5. 추천 시나리오

### 일상
1. 마이크로 30초 말하기 → 저장  
2. 타임라인에서 키워드 칩 확인  
3. 관계망에서 **사람·장소 위성**(썸네일 포함) 확인  

### 여행·나들이
1. 사진 + 「○○교에서 △△와」 메모  
2. 회상 탭에서 월별 확인  
3. **같은 장소 재방문** → 회상 알림  

### 사람 중심 추억
1. 검색 또는 타임라인 칩에서 **이름 탭**  
2. 관계망 **사람 렌즈** 또는 키워드 포커스  
3. 노드 탭 → AI 대화로 디테일 보강(Pro)

## 6. 문제 해결

| 증상 | 해결 |
|------|------|
| 회상 알림 없음 | 위치 **항상 허용**, 배터리 최적화 해제, GPS 있는 기억인지 확인 |
| 관계망 옛 이름 | 앱 재시작(자동 re-enrich) 또는 **관계망 데이터 정리** |
| 검색 결과 없음 | 프라이버시 모드면 **카드에 보이는 단어**로 검색 |
| 웹 안내가 안 열림 | 인터넷 연결 확인 · 설정 → **웹 안내** 다시 탭 |
| 위젯 추가 실패 | 위젯 삭제 후 재추가, 앱 최신 버전 설치 |
