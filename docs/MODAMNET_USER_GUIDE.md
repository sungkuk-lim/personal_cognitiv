# 모담넷(MemoryOS) 상세 이용 가이드 (사용자용)

**버전 1.0.12 · 2026년 7월**

앱 설정 → **이용 가이드**는 선택한 언어로 요약이 표시됩니다.
웹 상세 안내: https://sungkuk-lim.github.io/personal_cognitiv/user_guide.html

---

## 1. 모담넷이란?

음성·사진·동영상·텍스트로 남긴 **기억**을 타임라인에 쌓고, **관계망**으로 사람·장소·사건을 연결해 다시 찾아 주는 개인 기억 앱입니다.

- **기억 저장** — 말하기, 사진·동영상, 메모, (선택) 위치
- **자연어 검색** — 「어머니와 어제 저녁」처럼 말하듯 검색
- **관계망** — 허브·위성 트리, 종류별 색상, 드래그·롱프레스 이동
- **회상** — 월별 보기, 장소 근처 알림
- **프라이버시** — 게스트·프라이버시 모드로 기기에만 저장 가능
- **언어** — 한·영·일·중(간/번)·스·프·독·브라질 포·베트남

**핵심:** 입력은 항상 **자연어**로 하세요. 사람·장소·날짜·감정을 함께 말하면 검색·관계망·회상이 더 정확해집니다.

---

## 2. 처음 사용하기

1. **게스트**로 바로 쓰거나 **이메일 로그인**으로 클라우드·Pro를 준비합니다.
2. 하단 탭: **타임라인 · 검색 · 관계망 · 회상** (설정은 상단 톱니).
3. 첫 기억 예: 「오늘 광안리에서 어머니와 저녁 먹었어.」
4. 타임라인 카드 확인 → 관계망에서 사람·장소 연결 확인.

**권한:** 마이크 · 카메라/사진 · 알림 · 위치(항상 허용 권장 — 장소 회상).

---

## 3. 타임라인 — 기억 저장

| 방법 | 하는 일 |
|------|---------|
| 마이크 | 음성 또는 키보드 → 분석·저장 |
| 카메라 | 촬영/갤러리. 한 카드에 사진 여러 장 |
| 카드 탭 | 상세 · 편집 · 미디어 · 관계 태그 수정 |

**잘 되는 말하기**
- 「어제 어머니와 강남 식당에서 저녁 먹었어.」
- 「6월 22일 길안천에 가족과 놀러 갔다.」

카드에서: 본문 편집, 관계 태그 수정(관계망 반영), 사진·동영상 추가/삭제, 키워드 칩 → 관계망 포커스.

---

## 4. 검색 — 자연어로 찾기

| 모드 | 조건 | 예시 |
|------|------|------|
| AI 의미 검색 | 로그인 + Pro | 「민수랑 먹었던 식당 어디였지?」 |
| 로컬 자연어 | 게스트·무료·프라이버시 | 「어머니와 저녁」「오늘 사진」「광안리」 |

팁: 카드에 보이는 이름·장소·날짜를 말하듯 입력. 「오늘/어제/이번 주/지난달」 지원.

---

## 5. 관계망 — 연결 보기

일반 메모의 폴더·날짜와 달리 **무엇이 연결되는지**를 먼저 봅니다.

| 조작 | 설명 |
|------|------|
| 핀치 / 빈 곳 드래그 | 확대·화면 이동 |
| 노드 드래그 | 위치 이동(저장) |
| **허브 롱프레스 후 드래그** | 관련 위성과 함께 이동 |
| 기간 | 7 / 30 / 90일 / 전체 |
| 렌즈 | 사람 \| 기억 |
| 색상 | 사람·장소·활동·반려 등 종류별 |

### 노드에 사진·동영상

1. 사람·장소 등 **노드 탭**
2. 사진·동영상 추가
3. **그 노드에만** 표시됩니다.
   (회상에서 기억에 올린 미디어가 모든 위성에 퍼지지 않음)

(Pro) 노드 AI 대화로 디테일 보강 가능.

---

## 6. 회상

- 월별 사진·요약
- 카드 **길게 누르기** → 미디어 + 관계 미리보기
- 「관계망」→ 그 기억만 포커스
- 회상 보기 모드(설정): 공유 / 라이트 / 갤러리

### 장소 회상 알림

1. 장소 기반 회상 알림 ON + 알림 권한
2. 위치 **항상 허용**
3. 기억 저장 시 GPS
4. 배터리 최적화에서 모담넷 **최적화 안 함**

과거 GPS 장소 약 250m 이내 재방문 시 푸시.

## 8. 무료와 MemoryOS Pro

| 구분 | 무료·게스트·프라이버시 | Pro |
|------|------------------------|-----|
| 기억 저장 | 기기 즉시 | + 클라우드 동기화 |
| 관계망 | 로컬 골격 | + AI 인사이트·Graph AI |
| 검색 | 로컬 자연어 | + 의미 검색·AI 답변 |
| 사진 AI | 기본 | AI 분석 |
| 장소 회상 | 가능 | 가능 |

해지: Play 스토어 → 결제 및 구독.

## 10. 추천 시나리오

**일상:** 마이크 30초 → 칩 확인 → 관계망 위성
**여행:** 사진+메모 → 회상 월별 → 재방문 알림
**사람 중심:** 이름 검색/칩 → 사람 렌즈 → 해당 노드에만 미디어

## 11. FAQ · 문제 해결

| 증상 | 해결 |
|------|------|
| 회상 알림 없음 | 위치 항상 허용 · 배터리 최적화 해제 · GPS 기억 확인 |
| 옛 이름 노드 | 앱 재시작 · 관계망 데이터 정리 |
| 검색 없음 | 카드에 보이는 단어로 · 프라이버시면 AI 검색 불가 |
| 모든 노드에 동영상 | 1.0.12+ 업데이트 · 노드별 미디어는 선택 노드만 |
| 구매 복원 실패 | Play 설치본 확인 · 복원·상태 새로고침 |
| 드래그 느림 | 최신 버전 · 기간 필터로 노드 수 줄이기 |
| 데이터 분실 의심 | 백업 가져오기 · 계정 확인 |
