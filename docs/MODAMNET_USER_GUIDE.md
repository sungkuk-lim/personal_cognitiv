## 1. 모담넷이란?

음성·사진·동영상·텍스트로 남긴 **기억**을 타임라인에 쌓고, **관계망**으로 사람·장소·사건을 연결해 다시 찾아 주는 개인 기억 앱입니다.

- **기억 저장** — 말하기, 사진·동영상, 메모, (선택) 위치
- **자연어 검색** — 「지난달 제주도에서 뭐 했었는지」처럼 말하듯 질문
- **관계망** — 허브·위성 트리, 종류별 색상, 드래그·롱프레스 이동
- **회상** — 월별 갤러리, 사진 스와이프, 장소 근처 알림
- **기억 영상 (Pro)** — 사진으로 짧은 필름 미리보기·mp4 저장/공유
- **프라이버시** — 게스트·프라이버시 모드로 기기에만 저장 가능
- **언어** — 한·영·일·중(간/번)·스·프·독·브라질 포·베트남 (설정 상단)

**핵심:** 입력은 항상 **자연어**로 하세요. 사람·장소·날짜·감정을 함께 말하면 검색·관계망·회상이 더 정확해집니다.

## 2. 처음 사용하기

1. **게스트**로 바로 쓰거나 **이메일 로그인**으로 클라우드·Pro를 준비합니다.
2. 하단 탭: **타임라인 · 검색 · 관계망 · 회상** (설정은 상단 톱니).
3. 첫 기억 예: 「오늘 광안리에서 어머니와 저녁 먹었어.」
4. 타임라인 카드 확인 → 관계망에서 사람·장소 연결 확인.
5. (Pro) 설정 → **기억 영상 만들기** 또는 회상/하이라이트에서 필름 미리보기.

**권한:** 마이크 · 카메라/사진 · 알림 · 위치(항상 허용 권장 — 장소 회상).

## 3. 타임라인 — 기억 저장

| 방법 | 하는 일 |
|------|---------|
| 마이크 | 음성 또는 키보드 → 분석·저장 |
| 카메라 | 촬영/갤러리. 한 카드에 사진 여러 장 |
| 카드 탭 | 상세 · 편집 · 미디어 · 관계 태그 수정 |

**화면:** 같은 날짜끼리 묶여 보이고, 카드는 왼쪽 글·오른쪽 사진 썸네일 형태입니다. 키워드는 가로로 스크롤됩니다.

**잘 되는 말하기**
- 「어제 어머니와 강남 식당에서 저녁 먹었어.」
- 「6월 22일 길안천에 가족과 놀러 갔다.」

카드에서: 본문 편집, 관계 태그 수정(관계망 반영), 사진·동영상 추가/삭제, 키워드 칩 → 관계망 포커스.

## 4. 검색 — 자연어로 찾기

상단 검색창에 질문을 넣고 검색하면, **현재 검색 결과만** 한 화면에 표시됩니다. (이전 검색이 아래로 쌓이지 않습니다.)

| 구분 | 조건 | 화면 |
|------|------|------|
| 로컬 결과 | 항상(기기 기억) | 사진·제목·날짜·키워드 카드 목록 |
| AI 요약 | 로그인 + Pro | 목록 아래 강조 박스에 한 줄 요약 |

| 모드 | 조건 | 예시 |
|------|------|------|
| AI 의미 검색 | 로그인 + Pro | 「지난달 제주도에서 뭐 했었는지 알려줘」 |
| 로컬 자연어 | 게스트·무료·프라이버시 | 「어머니와 저녁」「오늘 사진」「광안리」 |

**필터 칩:** 복합 조건이 잡히면 상단에 칩이 뜹니다. **전체 해제**로 검색을 초기화합니다.

팁: 카드에 보이는 이름·장소·날짜를 말하듯 입력. 「오늘/어제/이번 주/지난달」 지원.

## 5. 관계망 — 연결 보기

| 조작 | 설명 |
|------|------|
| 핀치 / 빈 곳 드래그 | 확대·화면 이동 |
| 노드 드래그 | 위치 이동(저장) |
| **허브 롱프레스 후 드래그** | 관련 위성과 함께 이동 |
| 기간 | 7 / 30 / 90일 / 전체 |
| 렌즈 | 사람 \| 기억 |
| 색상 | 사람·장소·활동·반려 등 종류별 |

### 사진이 보이는 방식

- 기억 카드에 올린 사진은 **그 기억 카드**에 먼저 표시됩니다.
- 하루 묶음 허브는 **아직 다른 카드에 쓰이지 않은** 사진이 있을 때만 썸네일을 보여 줍니다.
- 사람·장소 위성에 올린 미디어는 **그 노드에만** 표시됩니다.

(Pro) 노드 AI 대화로 디테일 보강 가능.

## 6. 회상

- 월별로 펼침·접기
- 큰 사진 + 작은 사진 모자이크, **좌우 스와이프**로 넘기기
- 사진 탭 → 확대 보기 · 미디어 관리
- 아래쪽 **미니 관계망**으로 연결 미리보기
- 「관계망」→ 그 기억만 포커스
- (Pro) 하이라이트·배너에서 **기억 영상** 진입 가능
- 회상 보기 모드(설정): 공유 / 라이트 / 갤러리

### 장소 회상 알림

1. 장소 기반 회상 알림 ON + 알림 권한  
2. 위치 **항상 허용**  
3. 기억 저장 시 GPS  
4. 배터리 최적화에서 모담넷 **최적화 안 함**  

과거 GPS 장소 약 250m 이내 재방문 시 푸시.

## 6.1 기억 영상 (Pro)

사진으로 짧은 **기억 필름**을 만들고 기기에 mp4로 저장·공유합니다. (추가 요금 없음 · Google Play 구독에 포함)

### 만드는 방법

1. **설정 → 기억 영상 만들기**, 또는 회상/관계망 하이라이트의 영상 버튼  
2. 기억에 연결된 사진 또는 갤러리에서 사진 선택  
3. **길이 · 장수 · 필름 템플릿** 선택 (음악·전환·목소리 톤도 세부 조정 가능)  
4. **미리보기** → 필요하면 **저장** 또는 **공유**

### 필름 템플릿 (예)

| 템플릿 | 느낌 |
|--------|------|
| 클래식 | 균형 잡힌 기본 |
| 시네마틱 | 느린 줌 · 검정 페이드 |
| 가족 따뜻한 | 부드러운 전환 · 얼굴 중심 |
| 여행 다이어리 | 밝은 음악 · 팬 모션 |
| 인물 포커스 | 얼굴이 화면 중앙에 오도록 줌 |
| 추억 앨범 | 그리운 톤 · 느린 호흡 |

### 얼굴 중심 Ken Burns

사진에서 얼굴을 찾아(없으면 시각적 무게중심) **줌·팬의 중심**으로 씁니다. 미리보기와 내보낸 mp4가 같은 초점을 사용합니다.

### 내보내기 중 앱이 꺼졌을 때

렌더가 중간에 멈추면, 다음에 앱을 열 때 **이어서 완성** 안내가 뜰 수 있습니다. 알림이 오면 앱을 열어 완료하세요. (강제종료 중에도 백그라운드에서 계속 인코딩되지는 않으며, **체크포인트 후 이어하기** 방식입니다.)

## 12. FAQ · 문제 해결

| 증상 | 해결 |
|------|------|
| 회상 알림 없음 | 위치 항상 허용 · 배터리 최적화 해제 · GPS 기억 확인 |
