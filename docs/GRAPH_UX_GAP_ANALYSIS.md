## 1. 신뢰 (Trust)

### 문제
편집·AI 조각·entities 불일치 시 노드가 본문과 어긋남 → 그래프가 장식으로 느껴짐.

### 벤치마크
- Day One: 태그·사람이 본문과 1:1
- Apple Journal: 제안 엔티티를 사용자가 확인

### 모담넷 대응 (90% 목표)
| 조치 | 상태 |
|------|------|
| `freshGraphFragmentForMemory` — stale AI 무시 | ✅ |
| `entityLabelReferencedInMemory` — 옛 entities 제거 | ✅ |
| `GraphEntityContext` — 배지·위성 단일 소스 | ✅ |
| 가족 호칭(아들)은 허브 제목에 있어도 위성 유지 | ✅ |
| 장소(카페)는 제목 중복 시 위성 숨김 | ✅ |

**남은 갭:** 사용자 수동 엔티티 수정 UI (Phase 3)

---

## 2. 발견성 (Discoverability)

### 문제
“어디를 눌러야 위성이 나오는지” 모름.

### 벤치마크
- 대부분 상용 앱: 첫 실행 튜토리얼 또는 코치 마크

### 모담넷 대응
| 조치 | 상태 |
|------|------|
| 앱 온보딩에 관계망 한 줄 | ✅ |
| 관계망 탭 첫 방문 시트 (레일·기간·포커스) | ✅ |
| 도움말 시트 (`graph_help_sheet`) | ✅ |
| 왼쪽 레일 탭 = 위성 펼침 | ✅ (기존) |

**남은 갭:** 레일에 1회성 pulse 애니메이션 (Phase 2)

### 벤치마크

- Obsidian: 줌·필터·검색

### 모담넷 대응

|------|------|
| 기간 칩 (기본 7일) | ✅ |
| 키워드 포커스 서브그래프 | ✅ |

## 4. 상용 앱 대비 우위 유지

- 한국어 가족 호칭·별칭 (`canonicalEntityLabel`)
- 키워드 포커스 크로스 플로우 (타임라인→관계망)
- 로컬 게스트 모드에서도 관계망 동작
- 연락처 사진 노드 (`person_node_avatar`)
