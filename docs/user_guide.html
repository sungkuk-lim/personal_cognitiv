소개 관계망 차별화 기능·활용 환경설정 시나리오 개인정보 처리방침

1. 모담넷이란?

음성·사진·텍스트로 남긴 기억을 타임라인에 쌓고, 관계망으로 사람·장소·사건을 연결해 다시 찾아주는 개인 기억 앱입니다.

  • 기억 저장 — 말하기, 사진, 메모, 위치
  • 의미 검색 — 자연어 질문 (Pro·클라우드)
  • 관계망 — 인물·장소·감정·이벤트 그래프
  • 회상 — 월별 갤러리, 장소 알림
  • 프라이버시 — 기기 전용 저장 모드

2. 다른 앱과 다른 관계망

일반 메모·일기 앱은 시간순 목록이 중심입니다. 모담넷은 「무엇이 서로 연결되는가」를 먼저 보여 줍니다.

비교일반 앱모담넷
구조폴더·태그·날짜사람·장소·이벤트 허브 + 위성
연결수동 태그본문·AI 자동 추출, 편집 후 재정렬
탐색검색어 일치키워드 포커스 서브그래프
묶음앨범·캘린더사건 허브, 클러스터 간 황금 브리지
회상없음GPS 250m 이내 푸시 알림
신뢰태그=사용자 책임배지·노드·본문 단일 진실, 옛 이름 제거
편집 후에도 관계망이 본문과 맞게 유지됩니다 — 예: 「철수」→「민수」 수정 시 옛 노드가 사라집니다.

3. 핵심 기능과 활용법

타임라인

  • 마이크 — 음성·키보드 → 분석 및 저장
  • 카메라 — 사진 + 메모, 한 카드에 여러 장
  • 카드 탭 → 상세·편집·미디어 관리

검색

모드조건예시
AI 의미 검색로그인 + Pro「민수랑 먹었던 식당」
로컬 검색게스트·프라이버시「월영교」「6월」

관계망

  • 핀치·드래그, 기간 칩(7/30/90일), 엔티티 검색
  • 타임라인 키워드 칩 → 포커스 모드
  • 보라=AI 유사도, 녹=관계, 황금=클러스터 브리지

회상 · 위젯

  • 월별 사진·요약, 회상 보기 모드(설정)
  • 홈 위젯 — 기억 저장·검색·관계망 바로가기

4. 환경설정 가이드

앱 상단 톱니 → 설정

회상 알림 (중요)

  1. 「장소 기반 회상 알림」 ON + 알림 권한
  2. 위치 권한 → 시스템에서 항상 허용
  3. 기억 저장 시 GPS 허용
  4. 배터리 최적화 해제(삼성·샤오미 등)

사진 인식(OCR)

모드설명
하이브리드추천 — AI + 선택적 기기 OCR
저비용AI 해상도 낮춤, 한도 절약
AI 전용가장 풍부한 분석

관계망 · 프라이버시

  • 관계망 AI — Pro·로그인 시 백그라운드 분석
  • 관계망 데이터 정리 — 캐시·중복 정리
  • 프라이버시 모드 — 기기만 저장
  • 테마·언어·회상 모드 — 개인화

5. 추천 시나리오

일상

마이크 30초 → 타임라인 칩 확인 → 관계망 위성 확인

여행

사진+메모 → 회상 월별 보기 → 같은 장소 재방문 시 알림

사람 중심

이름 칩 탭 → 관계망 포커스 → 노드 AI 대화(Pro)

문제 해결

증상해결
알림 없음위치 항상 허용, 배터리 최적화 해제
옛 이름 노드앱 재시작 또는 관계망 데이터 정리
검색 없음프라이버시 모드면 카드 단어로 검색
