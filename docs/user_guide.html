1. 모담넷이란?

모담넷(MemoryOS)은 음성·사진·동영상·텍스트로 남긴 기억을 타임라인에 쌓고, 관계망으로 사람·장소·사건을 연결해 다시 찾아 주는 개인 기억 앱입니다.

  • 기억 저장 — 말하기, 사진·동영상, 메모, (선택) 위치
  • 자연어 검색 — 「어머니와 어제 저녁」처럼 말하듯 검색
  • 관계망 — 허브·위성 트리로 연결을 시각화
  • 회상 — 월별 보기, 장소 근처 알림
  • 프라이버시 — 게스트·프라이버시 모드로 기기에만 저장 가능
핵심 원칙: 입력은 항상 자연어로 하세요. 사람·장소·날짜·감정을 말하듯 넣으면 검색·관계망·회상이 더 정확해집니다.

2. 처음 사용하기

  1. 앱을 설치한 뒤 게스트로 바로 쓰거나, 이메일 로그인으로 클라우드·Pro를 준비합니다.
  2. 하단 탭: 타임라인 · 검색 · 관계망 · 회상 (설정은 상단 톱니).
  3. 첫 기억: 마이크 버튼으로 30초만 말해 보세요. 예) 「오늘 광안리에서 어머니와 저녁 먹었어.」
  4. 타임라인에 카드가 생기면 → 관계망에서 사람·장소 연결을 확인합니다.
권한 안내
· 마이크 — 음성 기억
· 카메라·사진 — 미디어 저장
· 알림 — 장소 회상·기억 펄스
· 위치(항상 허용 권장) — 장소 회상 알림

3. 타임라인 — 기억 저장

저장 방법

방법하는 일
마이크음성 또는 키보드 입력 → 분석·저장
카메라촬영 또는 갤러리. 한 카드에 사진 여러 장 가능
카드 탭상세 보기 · 본문 편집 · 사진·동영상 추가/삭제 · 관계 태그 수정

잘 저장되는 말하기 예시

  • 「어제 어머니와 강남 식당에서 저녁 먹었어.」
  • 「6월 22일 길안천에 가족과 놀러 갔다.」
  • 「오늘 찍은 사진 — 월영교 일몰, 바람이 시원했다.」
짧은 한 단어보다 사람 + 장소 + 날짜/시간 + 감정을 함께 넣으면 관계망 품질이 크게 올라갑니다.

카드에서 할 수 있는 일

  • 본문·요약 편집
  • 관계 태그(사람·장소 등) 수정 → 관계망에 반영
  • 사진·동영상 추가·삭제
  • 키워드 칩 탭 → 관계망 포커스

4. 검색 — 자연어로 찾기

모드조건예시
AI 의미 검색로그인 + MemoryOS Pro「민수랑 먹었던 식당 어디였지?」
로컬 자연어 검색게스트 · 무료 · 프라이버시 모드「어머니와 저녁」「오늘 사진」「광안리」

검색 팁

  • 카드에 보이는 이름·장소·날짜를 그대로 말하듯 입력
  • 「오늘 / 어제 / 이번 주 / 지난달」 등 날짜 표현 지원
  • 사진·동영상만 찾을 때: 「사진」「동영상」「영상」 포함
프라이버시·게스트 모드에서는 클라우드 AI 검색이 꺼집니다. 타임라인에 보이는 단어 중심으로 검색하세요.

5. 관계망 — 연결 보기

일반 메모 앱의 폴더·날짜 목록과 달리, 모담넷은 무엇이 서로 연결되는지를 먼저 보여 줍니다.

비교일반 앱모담넷
구조폴더·태그허브 + 위성 (트리형)
연결수동 태그본문에서 자동 추출 · 편집 후 재정렬
탐색검색어 일치키워드 포커스 · 렌즈(사람/기억)
미디어—선택한 노드에만 사진·동영상

화면 조작

  • 핀치 — 확대·축소 · 드래그(빈 곳) — 화면 이동
  • 노드 드래그 — 위치 이동 (저장됨)
  • 허브 롱프레스 후 드래그 — 관련 위성 노드와 함께 이동
  • 기간 — 7일 / 30일 / 90일 / 전체
  • 렌즈 — 사람 | 기억 (같은 데이터의 다른 관점)
  • 색상 — 사람·장소·활동·반려 등 종류별 색으로 구분

노드에 사진·동영상 올리기

  1. 사람·장소·활동 등 노드를 탭합니다.
  2. 「사진·동영상 보기」또는 미디어 화면에서 추가합니다.
  3. 올린 미디어는 그 노드에만 표시됩니다. (회상에서 기억에 올린 미디어가 모든 위성에 퍼지지 않습니다.)
기억 카드(타임라인·회상)에 올린 사진·동영상은 그 기억·허브에 연결됩니다. 특정 인물·장소에만 붙이려면 해당 노드를 선택해 올리세요.

노드 탭 후 할 수 있는 일

  • 사진·동영상 관리
  • 연결 기억 보기
  • (Pro) 노드 AI 대화로 디테일 보강
  • 사람 노드 — 연결 차수·통계 확인

6. 회상 — 다시 떠올리기

  • 월별로 사진·요약 보기
  • 카드 길게 누르기 — 사진·동영상과 함께 관계 미리보기
  • 「관계망」버튼 — 그 기억만 포커스
  • 설정에서 회상 보기 모드: 공유 / 라이트 / 갤러리

장소 기반 회상 알림

  1. 설정 → 장소 기반 회상 알림 ON + 알림 권한
  2. 위치 권한 → 시스템에서 항상 허용
  3. 기억 저장 시 GPS 허용
  4. (삼성·샤오미 등) 배터리 최적화에서 모담넷 최적화 안 함

과거 기억을 남긴 장소 근처(약 250m)에 다시 가면 푸시로 알려 줍니다.

8. 무료와 MemoryOS Pro

구분무료 · 게스트 · 프라이버시MemoryOS Pro
기억 저장기기에서 즉시클라우드 동기화
관계망로컬 규칙으로 구성+ AI 인사이트·Graph AI
검색로컬 자연어·키워드의미 검색·AI 답변
사진 분석기본AI 분석
장소 회상 알림가능가능

구독은 Google Play에서 관리합니다. 해지: Play 스토어 → 결제 및 구독.

구매 복원

설정 → MemoryOS Pro → 구매 복원. 같은 Google 계정으로 Play에서 설치한 기기에서 실행하세요.

9. 홈 화면 위젯

  1. 홈 화면 빈 곳 길게 누르기 → 위젯
  2. 모담넷 / MemoryOS 위젯 추가
  3. 최신 기억 미리보기 · 기억 저장 · 검색 · 관계망 바로가기
위젯이 안 보이면 앱을 최신으로 업데이트한 뒤 위젯을 삭제하고 다시 추가하세요.

10. 추천 사용 시나리오

일상

  1. 마이크로 30초 말하기 → 저장
  2. 타임라인에서 키워드 칩 확인
  3. 관계망에서 사람·장소 위성 확인

여행·나들이

  1. 사진 + 「○○에서 △△와」 메모
  2. 회상 탭에서 월별 확인
  3. 같은 장소 재방문 → 회상 알림

사람 중심 추억

  1. 검색 또는 칩에서 이름 탭
  2. 관계망 사람 렌즈 / 포커스
  3. 해당 노드에만 사진·동영상 추가
  4. (Pro) 노드 AI로 디테일 보강

11. 자주 묻는 질문 · 문제 해결

증상해결
회상 알림이 안 옴위치 항상 허용, 배터리 최적화 해제, GPS가 붙은 기억인지 확인
관계망에 옛 이름이 남음앱 재시작 또는 설정 → 관계망 데이터 정리
검색 결과 없음카드에 보이는 단어로 검색 · 프라이버시 모드면 AI 검색 불가
모든 노드에 동영상 표시최신 버전(1.0.12+)으로 업데이트 · 노드별 미디어는 해당 노드에만 표시
구매 복원 안 됨Play 스토어 설치본인지 확인 · 구매 복원 재시도 · 구독 상태 새로고침
드래그가 느림최신 버전으로 업데이트 · 기간 필터를 줄여 노드 수 감소
위젯 추가 실패위젯 삭제 후 재추가 · 앱 최신 설치
데이터가 사라진 것 같음설정 → 백업 가져오기 · 같은 Google/계정인지 확인

무료 vs Pro를 헷갈릴 때

관계망 골격과 키워드 검색은 무료에서도 동작합니다. 「의미 검색·AI 답변·사진 AI·관계망 AI」는 Pro입니다. 검색 화면에 로컬/Pro 안내 배너가 표시됩니다.
