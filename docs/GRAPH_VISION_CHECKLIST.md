# 관계망 비전 vs 구현 체크리스트

MemoryOS( personal_cognitive )가 지향하는 **「관계망 기반 기억 탐색」** 과 현재 코드 기준 구현 상태를 대조한 문서입니다.  
상용 로드맵·QA·기능 우선순위 논의용으로 사용하세요.

**기준일:** 2026-06-17  
**관련 코드:** `lib/features/graph/`, `lib/services/graph_query_engine.dart`, `lib/services/search_answer_service.dart`, `lib/utils/memory_entity_extract.dart`

---

## 1. 비전 한 줄 요약

> 기억을 **타임라인 나열**이 아니라 **사람·장소·맥락·감정 등이 연결된 그래프**로 두고,  
> 사용자가 자연어로 질문하면 AI가 **공통점을 찾아** 관련 추억을 묶어 보여 준다.

## 2. 축별 구현 현황 (요약)

| 축 | 비전 | 현재 | 상태 |
|----|------|------|------|
| **사람** | 같은 사람 추억 자동 묶음 | 엔티티 추출, 위성 노드, 키워드 포커스, 공유 인물 브리지, 「함께」 질의 | **강함** |
| **장소** | 같은 장소 기억 연결 | 장소 추출·위성, 회상 앵커, 장소 알림, 장소 키워드 검색 | **강함** |
| **이벤트·활동** | 회식·여행·나들이 등 묶음 | `eventTitle`, 활동 위성, 하루 묶음 허브 | **중간** |
| **감정** | 행복·슬픔 등으로 모아보기 | `tag:emotion:`·관계 `감정`·위성·검색 필터 | **강함** |
| **음식** | 음식으로 추억 연결 | Graph AI 프롬프트에서 **위성 제외** 설계 | **의도적 미구현** |
| **취미·계절·날씨** | 테마별 추천 | 전용 엔티티·축 없음 | **없음** |
| **미디어** | 「광안리 사진만」 등 | `type: image`, 사진 검색 쿼리, 썸네일 노드 | **부분** |
| **자연어 복합 질의** | 사람+감정+장소 동시 조건 | `MemoryQuery` AND 필터·칩·traverse | **강함** |
| **관계(Relationship)** | 동행·방문·식사 등 라벨 엣지 | `rel:` 태그·녹색 라벨 선·이벤트 허브 연결 | **중간→강함** |
| **이벤트 허브** | 사건 중심 묶음 | `event:` 태그·**이벤트 허브 보기** 전환 | **중간→강함** |
| **엔티티 통합** | 어머니=엄마 | `canonicalEntityLabel`·별칭 사전 | **중간** |
| **중요도** | ★별 기억 가중 | `importance:1~5`·검색·회상 정렬 | **중간** |
| **시간 계층** | 연→계절→월 | `time:year/season/month` 태그 | **중간** |
| **AI 그래프 탐색** | 관계망을 정확히 traverse | 저장 시 조각 생성·노드 대화(Pro); 전역 그래프 에이전트 없음 | **부분** |

**범례:** **강함** = MVP 이상으로 일상 사용 가능 · **중간** = 동작하나 규칙/엣지 케이스 많음 · **약함** = 프로토타입 수준 · **없음** = 미착수

## 4. 예시 질문 vs 현재 동작

| 사용자 질문 (비전) | 기대 | 현재 동작 | 정확도 |
|-------------------|------|-----------|--------|
| 어머니와 함께했던 기억 | 어머니 엔티티 묶음 | 키워드·엔티티 매칭 + 관계망 포커스 | **높음** |
| 어머니와 **행복한** 식사만 | 사람 ∧ 감정 ∧ 활동 | `어머니`·`행복`·`식사` 각각 부분 매칭, **동시 조건 없음** | **낮음** |
| 광안리에서 찍은 **사진**만 | 장소 ∧ image | `광안리` 검색 + 사진 쿼리 **별도**; 복합 AND 미보장 | **중간** |
| 철수와 카페 이야기 | 사람 + 장소 위성 | 위성 분리 (철수, 카페) | **높음** (최근 개선) |
| 여름에 여행한 추억 | 계절 ∧ 활동 | 「여행」 키워드만; 계절 축 없음 | **낮음** |
| 비 오는 날 기억 | 날씨 | 미지원 | **없음** |
| 탕수육 먹었던 날 | 음식 | 음식 위성 제외 설계 | **없음** |

## 5. 비전과의 거리 (정직한 평가)

### 이미 비전과 맞는 부분
- **관계망이 1급 탭**이고, 타임라인 키워드와 연동됨
- **사람·장소**는 저장 → 추출 → 그래프 → 검색 → 회상까지 **일관된 축**
- **로컬 우선** MVP에 임베딩·규칙·(선택) AI가 **겹겹이** 보완

### 아직 비전만큼은 아닌 부분
- **복합 자연어**는 「검색 + 요약」에 가깝고, 「그래프 질의 엔진」은 아님
- **감정·음식·취미·계절·날씨**는 비전 표의 절반 이상이 **미구현 또는 의도적 제외**
- AI는 **정리·요약·노드 대화**에 강하고, **임의 그래프 탐색 에이전트**는 없음

### 한 줄 결론
> **방향과 골격은 같다. 완성도는 「사람·장소·이벤트 중심 로컬 MVP」 수준.**

## 7. QA 시 확인할 시나리오

관계망·검색 회귀 테스트 시 아래를 수동으로 돌리면 좋습니다.

1. **친구** 카테고리 · 「철수와 카페에서 3시간 이야기」 → 관계망 위성 **철수 + 카페** (합성 이벤트 없음)
2. 타임라인 **광안리** 키워드 탭 → 포커스 허브에 **조직** 부제 없음, 드래그 유지
3. 집에서 광안리 이야기 저장 → 회상 앵커 시트 → **회상 연결** 배지
4. 검색 「어머니」→ 엔티티 매칭 기억 상위
5. 검색 「사진」→ image 타입 우선
6. (Phase E) 관계망 **이벤트 허브** ↔ **기억 허브** 전환 · 녹색 **동행·방문** 라벨 선
7. 기존 기억 **재저장 또는 편집** 후 `rel:`·`event:` 태그 생성 확인

자동 테스트: `test/graph_*`, `test/memory_graph_semantics_test.dart`, `test/memory_query_test.dart`
